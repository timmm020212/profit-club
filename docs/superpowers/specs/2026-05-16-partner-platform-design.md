# Партнёрская платформа — Дизайн MVP

**Дата:** 2026-05-16  
**Статус:** Одобрено  
**Этап:** 1 из 3 (Basic тариф, только веб)

---

## Суть

Трансформация Profit Club из одно-салонного приложения в мульти-тенантную платформу. Салоны-партнёры получают готовую систему онлайн-записи под своим брендом. Мы берём фиксированную ежемесячную подписку.

---

## Архитектурный подход

**Расширение текущего стека** — добавляем `salonId` ко всем таблицам БД. Существующий Profit Club становится первым партнёром на платформе. Никакого нового отдельного проекта — всё в одном Next.js приложении.

Стек без изменений: Next.js 15 · TypeScript · PostgreSQL (Supabase) · Drizzle ORM · Tailwind.

---

## Флоу онбординга партнёра

1. Менеджер платформы создаёт инвайт → партнёр получает ссылку вида `/partner/join?invite=TOKEN`
2. Партнёр заполняет регистрационную форму: название салона, ИНН, ФИО, телефон
3. Выбирает тариф (без оплаты на старте MVP — просто выбор)
4. Получает доступ в кабинет `/partner/dashboard`
5. Менеджер платформы отдельно договаривается об условиях и активирует подписку вручную

## Страница клиента

URL: `{домен}/salon/{slug}`

Партнёр даёт эту ссылку своим клиентам. Страница показывает:
- Название и описание салона
- Список услуг с ценами
- Кнопка «Записаться» → стандартный флоу записи (выбор мастера → слота → подтверждение)

Никакого общего каталога салонов на этом этапе.

## Кабинет партнёра

**Дизайн:** Светлый (белый фон, серые карточки), графитовый акцент (`#1a1a2e`), без красного.  
**Навигация:** Шапка с названием салона + иконка «три полоски» → боковая панель на ~80% ширины экрана.

### Пункты меню

**Главное**
- Главная — дашборд: записи сегодня, счётчики
- Записи — полный список записей, статусы, отмена

**Управление**
- Услуги — добавить / редактировать услуги, цены, категории
- Мастера — список мастеров, специализации, фото
- Расписание — рабочие слоты мастеров
- Моя страница — ссылка на клиентскую страницу + QR-код

**Аккаунт**
- Профиль салона — название, адрес, фото, контакты
- Тариф и оплата — текущий тариф, дата продления
- Выйти

## Новые таблицы БД

```
salons
  id, slug, name, ownerName, phone, inn, city
  tariff (basic|advanced|pro)
  isActive, inviteToken
  createdAt

partner_users
  id, salonId (FK), email, passwordHash
  createdAt
```

Все существующие таблицы (`services`, `masters`, `appointments`, `workSlots`, `clients`) получают поле `salonId`.

## Аутентификация партнёров

Отдельная от текущей NextAuth. Партнёры логинятся через email + пароль в `/partner/login`. Сессия хранится в отдельном JWT-куки `partner-session`. Middleware защищает все `/partner/*` маршруты.

- Общий каталог салонов
- Telegram-боты для партнёров
- Аналитика и отчёты
- Мобильное приложение
